Repository Security

Intended Users

This repo is for me, my instructor, and the teaching assistants. I use it to store my class assignments, and they may need to access it to review and grade my work.

Security Risks

The risk is fairly low since this repo is mainly schoolwork. However, someone could copy my assignments or change my code if they gained write access. Accidentally uploading passwords, API keys, or personal information would create a more serious risk.

Keeping the Repo Secure

Since this is an individual class repo, a CODEOWNERS file and required pull request reviews are not necessary for my current setup. Those would be more useful if several people were contributing. I still need to check what I commit, keep sensitive information out of the repo, and limit write access
